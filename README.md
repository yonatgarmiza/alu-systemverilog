**8-bit ALU – SystemVerilog**

An 8-bit combinational Arithmetic Logic Unit (ALU) implemented in SystemVerilog, including a self-checking testbench for functional verification.

**Supported Operations**
- ADD
- SUB
- AND
- OR
- XOR

**Status Flags**
- Zero
- Carry-Out
- Signed Overflow

**Verification**

Developed a self-checking testbench using reusable tasks and assertions to verify arithmetic and logic operations, including status flags and boundary conditions.

**Tools**
- SystemVerilog
- Xilinx Vivado
