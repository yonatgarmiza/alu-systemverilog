**8-bit ALU – SystemVerilog**

An 8-bit combinational Arithmetic Logic Unit (ALU) implemented in SystemVerilog, including a self-checking testbench for functional verification.

**Supported Operations**
- ADD
- SUB
- AND
- OR
- XOR

**Status Flags**
- Zero
- Carry-Out
- Signed Overflow

**Verification**
- Self-checking testbench using reusable tasks.
- Assertions to check ALU outputs and status flags.
- Directed test scenarios covering arithmetic and logic operations.
- Boundary and overflow test cases.

**Tools**
- SystemVerilog
- Xilinx Vivado
